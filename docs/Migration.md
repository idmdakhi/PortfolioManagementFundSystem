## تفاوت‌های عمدی نسبت به اکسل
(`BusinessRules.md` بخش ۱) سود نقدی یک‌بار شمرده می‌شود (اکسل دوبار → کارمزد ۱۰۰٬۰۰۰ ریال بیشتر)، سهم کارمزد هر نفر یک‌بار کم می‌شود، سود ثابت با ماه‌ها متناسب است.

## چک‌لیست مهاجرت یک فایل جدید (دستی)
۱. نسخه‌ای دست‌نخورده از اکسل نگه دارید و تاریخ برش را تعیین کنید.
۲. برای هر سرمایه‌گذار: واحد و بهای ابتدایی، حساب شخصی دوره (ابتدا/واریز/برداشت/ارزش).
۳. برای دوره: ارزش ابتدا/پایان، واریز و برداشت پیش از سیستم، نرخ‌ها.
۴. پس از ورود، صفحه‌های «تطبیق» و «سود و زیان صندوق» را با اکسل مقایسه کنید: NAV، کل واحد، کارمزد، سود خالص هر نفر.
۵. هر اختلاف را با علت (گردکردن/قاعدهٔ عمدی/خطا) یادداشت کنید.

## ارتقای نسخهٔ برنامه روی داده موجود
```
(پشتیبان JSON بگیرید + فایل دیتابیس را کپی کنید)
npm install
node ace codegen
node ace migration:run      # فقط جدول audit_logs اضافه می‌شود؛ هیچ ردیفی تغییر نمی‌کند
```
این مسیر روی کپی دیتابیس واقعی آزموده شد: شمار همهٔ جدول‌ها قبل و بعد برابر بود.
