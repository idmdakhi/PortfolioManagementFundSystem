# دفتر مالی، اصلاح و تطبیق

## چه چیزی «دفتر» است
- **واحدها**: `transactions` (+ واحد/بهای اولیهٔ `investors`).
- **پول صندوق**: دفتر `valuations` + جریان‌های نقدی بعد از آخرین ارزش‌گذاری.
- **حوزه‌ها**: `area_entries`.
هیچ مانده‌ای ذخیره نمی‌شود؛ همه از این دفترها ساخته می‌شود.

## اصلاح و ابطال
طراحی فعلی (D-03): تراکنش‌ها در دورهٔ باز **قابل ویرایش و حذف فیزیکی**‌اند، به شرط نشکستن قواعد صحت؛ دورهٔ بسته قفل است. برای اینکه تغییر «بی‌ردپا» نباشد:
- پیش از هر ویرایش/حذف رکوردهای مالی، **مقدار قبل** و بعد در `audit_logs` (`kind='change'`) ذخیره می‌شود.
- هر درخواست نوشتن (چه موفق چه رد شده) با کاربر، IP و زمان در `audit_logs` (`kind='request'`) می‌ماند.
- بازیابی پشتیبان و بستن دوره هم ثبت می‌شوند.
تبدیل به دفتر «فقط اضافه‌شونده» با تراکنش معکوس در `todo.md` است.

## تطبیق مالی (`app/services/reconcile.ts`)
صفحهٔ `/reconciliation` و نشان هشدار در داشبورد. هر بررسی `ok`/`error`/`warning` دارد و خروجی تغییر خودکار ندارد (فقط گزارش).

| بررسی (`id`) | سطح اختلاف |
| --- | --- |
| `units-non-negative`: واحد هیچ سرمایه‌گذاری در هیچ تاریخی منفی نیست | error |
| `tx-units-consistent`: واحد هر تراکنش = مبلغ ÷ NAV | error |
| `dates-in-period`: تاریخ همهٔ رکوردها (تراکنش، سود، کارمزد، حوزه، ارزش‌گذاری) داخل یک دوره است | error |
| `periods-no-overlap`: دوره‌ها هم‌پوشانی ندارند | error |
| `single-open-period`: حداکثر یک دورهٔ باز | error |
| `nav-positive`: NAV دوره‌های دارای واحد مثبت است | error |
| `investor-values-sum`: جمع ارزش سرمایه‌گذاران = ارزش بازار − کارمزد باقی‌مانده (تلورانس ۱ ریال) | error |
| `fee-units-linked`: هر تراکنش `kind='fee'` یک رسید `units` هم‌مبلغ دارد و برعکس | error |
| `area-balances`: مانده هیچ‌کس در هیچ حوزه‌ای منفی نمی‌شود | error |
| `fee-not-overpaid`: تسویهٔ کارمزد از کارمزد محاسبه‌شده بیشتر نیست | warning |
| `period-continuity`: ارزش ابتدای دوره = پایان دورهٔ قبل − کارمزد باقی‌مانده | warning |
| `valuation-fresh`: آخرین ارزش‌گذاری دورهٔ باز قدیمی‌تر از ۴۵ روز نیست | warning |

عمداً بررسی نمی‌شود: «جمع سرمایهٔ افراد = سرمایهٔ صندوق». صدور واحد کارمزد در سرمایهٔ سبدگردان می‌آید ولی در سرمایهٔ صندوق نه (پولی وارد نشده)، پس این برابری ذاتاً برقرار نیست و هشدار کاذب می‌داد.

روی دادهٔ واقعی (کپی دیتابیس پروژه) همهٔ بررسی‌های خطا سالم‌اند و تنها هشدار، «ارزش‌گذاری قدیمی» است (آخرین ارزش‌گذاری ۱۴۰۴/۱۲/۲۹ در دورهٔ ۱۴۰۵).

بستن دوره با هر `error` رد می‌شود (پیام فهرست اختلاف‌ها).
