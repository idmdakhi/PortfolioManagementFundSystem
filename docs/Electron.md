# Electron (بستهٔ دسکتاپ)

**وضعیت: خارج از محدودهٔ این پروژه.**
این پروژه یک وب‌اپ AdonisJS است که محلی با `npm run dev` یا روی سرور با `npm run build && npm start` اجرا می‌شود. پوشه‌های `electron/`, `data/`, `core/` و Drizzle که در مستند معماری قدیمی آمده بودند در این مخزن وجود ندارند (← `DECISIONS.md` D-08).

اگر روزی بستهٔ دسکتاپ لازم شد، مسیر پیشنهادی: اجرای همین سرور داخل فرایند اصلی Electron روی `127.0.0.1` با پورت تصادفی، نگه‌داری `DB_PATH` در پوشهٔ دادهٔ کاربر، و بدون تغییر در لایهٔ سرویس‌ها.
