# نیازمندی‌ها

## کاربران
- **مدیر (`admin`)**: همهٔ عملیات ثبت، ویرایش، حذف، تنظیمات، پشتیبان.
- **مشاهده‌گر (`viewer`)**: فقط خواندن گزارش‌ها و دریافت خروجی.
