# واژه‌نامه

| اصطلاح | معنی |
| --- | --- |
| NAV | ارزش خالص هر واحد صندوق = (ارزش بازار − کارمزد باقی‌مانده) ÷ کل واحدها |
| واحد | سهم مالکیت در صندوق؛ با صدور افزوده و با ابطال کم می‌شود |
| صدور | ورود پول و ایجاد واحد (`issue`) |
| ابطال | خروج پول و کاهش واحد (`redeem`) |
| ارزش بازار | ارزش کل صندوق در تاریخ ارزش‌گذاری، به‌علاوهٔ جریان‌های نقدی بعد از آن |
| سرمایه (Capital) | ارزش ابتدای دوره + واریز − برداشت |
| سود ناخالص | افزایش ارزش نسبت به سرمایه + سود نقدی، پیش از کارمزد |
| سود ثابت مشتری | بازده تضمینی (نرخ بانکی) که پیش از سهم عملکرد کسر می‌شود |
| کارمزد عملکرد | درصدی از سودِ بالاتر از سود ثابت |
| سبدگردان | مدیر صندوق؛ دریافت‌کنندهٔ کارمزد |
| حوزه | محل سرمایه‌گذاری بیرون از صندوق (نقدی/ملک/…) |
| حرکت گروهی | یک عملیات که بین چند نفر تقسیم و اتمیک ثبت می‌شود |
| دورهٔ باز/بسته | دورهٔ مالی قابل ثبت / قفل‌شده |
| تطبیق | مقایسهٔ خودکار مجموع‌ها و قواعد صحت؛ فقط گزارش می‌دهد |
| حسابرسی | ثبت ردپای هر تغییر: چه کسی، چه وقت، چه چیز، قبل و بعد |
| ریال | واحد پول؛ همهٔ مبالغ صحیح |
| Legacy (ستون) | مقدار قدیمی ذخیره‌شده در دوره که دفتر ارزش‌گذاری جایگزین آن شده |
