# صندوق سبدگردانی خانوادگی (AdonisJS 7 + SQLite)

ورود با نقش (مدیر / فقط‌مشاهده)، دیتابیس، دادهٔ اولیه از اکسل، ماژول محاسبات تست‌شده.

امکانات: حساب صندوق و حساب شخصی جدا از هم، گزارش چاپی ترکیبی برای مشتری (صندوق + شخصی + حوزه‌ها، چاپ یا ذخیره PDF)، حرکت گروهی (تقسیم یک مبلغ بین چند نفر و انتقال بین صندوق، حوزه‌های سرمایه‌گذاری مثل نقدی و ملک، و خارج از سیستم)، خلاصه و NAV هر دوره، سود و زیان دوره‌های مالی (صندوق و حساب شخصی)، سرمایه‌گذاران، تراکنش‌ها (ثبت، ویرایش، حذف)، سود تقسیمی (صندوق و شخصی)، تاریخ شمسی، جداکنندهٔ هزارگان در مبلغ‌ها، صفحهٔ فرمول‌ها، بستن دوره و شروع دورهٔ بعد.

> به‌روزرسانی از نسخهٔ قبل (بدون از دست رفتن داده): فایل‌های جدید را روی پروژه کپی کنید، سپس
> `node ace codegen` و `node ace migration:run` را بزنید. مهاجرت جدید فقط جدول‌های `areas` و `area_entries` و ستون `batch_id` را اضافه می‌کند.

## اجرا روی ویندوز

۱. **Node.js 24 (LTS)** را از nodejs.org نصب کنید. (AdonisJS 7 به Node 24 یا بالاتر نیاز دارد.)
۲. پوشه را از حالت zip درآورید و در PowerShell داخلش بروید:

```powershell
npm install
copy .env.example .env
node ace generate:key
node ace codegen
node ace migration:run
node ace db:seed
npm run dev
```

۳. مرورگر: http://localhost:3333
   ورود اولیه: `admin@example.com` / `ChangeMe-123`
   (پیش از `db:seed` می‌توانید `ADMIN_EMAIL` و `ADMIN_PASSWORD` را در `.env` عوض کنید.)

## تست

```powershell
node ace test unit
```

تست‌ها با اعداد خود اکسل نوشته شده‌اند (NAV برابر ۲۲٬۲۹۲٫۱۸۸۷ و کارمزد ۲۰۱٬۷۰۰٬۰۰۰ ریال).

## ساختار

- `app/services/fund_calculator.ts`: محاسبات خالص (بدون دیتابیس)، عیناً از اکسل
- `app/services/fund_state.ts`: ساخت وضعیت دوره از روی دیتابیس و تراکنش‌ها
- `app/services/jalali.ts`: تبدیل تاریخ شمسی و میلادی
- `database/migrations`: جدول‌ها (`users` با `role`, `periods`, `investors`, `transactions`, `personal_accounts`, `dividends`, `history_periods`)
- `database/schema.ts`: کلاس‌های مدل که Lucid از روی migrationها می‌سازد (دستی ویرایش نکنید)
- `database/seeders/main_seeder.ts`: دادهٔ اولیه از اکسل
- دیتابیس: فایل `tmp/db.sqlite3` (برای پشتیبان‌گیری همین فایل را کپی کنید). همچنین از صفحهٔ تنظیمات می‌توانید پشتیبان کامل JSON دانلود یا بازیابی کنید.

## نکته‌های طراحی

- واریز، برداشت و ارزش روز از روی تراکنش‌ها ساخته می‌شوند. تراکنش‌های دورهٔ باز قابل ویرایش و حذف‌اند (به شرط منفی نشدن واحدها)؛ دورهٔ بسته قفل است.
- تاریخ‌ها در دیتابیس میلادی ذخیره و به شمسی نمایش داده می‌شوند.
- واحدها `double` هستند (مثل اکسل). مبلغ‌ها ریال صحیح‌اند.
- فرمول‌ها و تفاوتشان با اکسل در صفحهٔ «فرمول‌ها» داخل برنامه آمده است.
